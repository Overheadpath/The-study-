# 🚀 Beanie Pro v2.0 - Quick Start Guide

## Installation (2 Minutes)

1. **Open Chrome Extensions**
   - Navigate to `chrome://extensions/`
   - Enable "Developer mode" (top right toggle)

2. **Load Extension**
   - Click "Load unpacked"
   - Select the `/app/BeanieMethod` folder
   - Extension icon appears in toolbar

3. **Log into Roblox**
   - Open Roblox.com in a new tab
   - Log in to your account

4. **You're Ready!** Click the extension icon 🎯

---

## First Time Setup (1 Minute)

### Scanner Tab (Default)
- Extension auto-scans on first open
- Wait for scan to complete OR click "Skip"
- Browse servers and click "Join" to play

### Enable Auto-Refresh
- ✅ Check "Auto-refresh (every 3 min)"
- Scanner will refresh automatically

## Key Features at a Glance

### 🖥️ Scanner Tab
**Find and join servers fast**
- Browse private servers with pagination

## Most Used Actions

### Join a Safe Server
1. Scanner tab → Wait for scan
2. Look for ⚠️ WARNING badge (avoid these)
3. Click "Join" on safe server

### Track Missing Brainrots
1. Brainrots tab → "Refresh Brainrots"
2. See red "✗ Missing" badges
3. Join servers to collect them

### Send Friend Requests to Players
1. Let Scanner scan servers (collects players)
2. Friends tab → "Send Requests to Players"
3. Confirm → Bulk requests sent

### Find Mutual Friends
1. Friends tab → "Scan Mutuals"
2. Wait for scan to complete
3. See blue "X Mutuals" badges

### Clean Up Friend List
1. Friends tab → Select friends
2. Click "Remove Selected" OR
3. Click "Remove Selected" with none checked
4. Choose bulk option from modal

## Troubleshooting

**"Please log in to Roblox"**
- Open Roblox.com and log in
- Refresh extension

**Rate Limited (429 Error)**
- Extension auto-waits 5 seconds
- Reduce bulk operation frequency

**Brainrots Not Loading**
- Click "Clear Cache" then "Refresh"
- Verify you're logged into Roblox

**Auto-Refresh Not Working**
- Check if checkbox is enabled
- Must be on Scanner tab
- Timer runs every 3 minutes
